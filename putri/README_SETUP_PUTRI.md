# Bendahara PUTRI PPFHA — backend modular

Backend Apps Script dipisahkan menjadi sembilan file di folder `bendahara/`. Salin masing-masing file ke file Script tersendiri dalam satu project Apps Script bernama **Bendahara PUTRI PPFHA**.

Database tetap menggunakan Google Sheets PUTRI yang sudah dipakai Program PUTRI. Project dan deployment Bendahara terpisah. Tidak mengubah script Program PUTRI, deployment SPP PUTRI, atau sistem PUTRA.
